# Maintainers

Maintainers hold commit rights to this repository. They review and merge pull requests,
triage issues, and look after the health of the areas they cover.

This list governs commit access to this repository only. It is not the Technical Steering
Committee roster, which is in [CONTRIBUTING.md](CONTRIBUTING.md). Maintainer status is a
prerequisite for a TSC seat but does not confer one, and most maintainers will not hold a
seat.

Every repository in the OpenDCKit organization keeps its own copy of this file.

## Changes to this list

Adding or removing a maintainer is done by pull request against this file. An existing
maintainer of this repository nominates, the maintainers of this repository vote, and a
carried nomination then goes to the TSC for approval before the pull request merges. An
initial set of maintainers may instead be approved by the TSC when the repository is
created. See [CONTRIBUTING.md](CONTRIBUTING.md) for the full process.
