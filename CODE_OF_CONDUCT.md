# Code of Conduct

OpenDCKit is a project of LF Projects, LLC. Everyone taking part in the project is expected to follow the LF Projects Code of Conduct, which applies in every OpenDCKit repository, meeting, mailing list and chat channel:

https://lfprojects.org/policies/code-of-conduct/

The Technical Steering Committee may adopt a project-specific code of conduct with the approval of the Series Manager. Until it does, the policy above applies.

## Reporting a concern

Report concerns to the TSC chair, or to conduct@lfprojects.org if you would rather raise it outside the project.
