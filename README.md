# .github

Organization-wide defaults for [OpenDCKit](https://github.com/opendckit). GitHub applies the
files here to every repository in the organization that does not provide its own.

| File | What it is |
| ---- | ---------- |
| [CONTRIBUTING](CONTRIBUTING) | How to take part: the roles in the project, how to open a pull request, the sign-off required on every commit, how decisions are made, and licensing |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | The code of conduct that applies across the project, and how to raise a concern |
| [MAINTAINERS.md](MAINTAINERS.md) | Who holds commit rights to this repository |
| `profile/README.md` | The text shown on the organization's landing page at github.com/opendckit |

This repository is not the Technical Steering Committee roster and not the governance record.
Those live in [opendckit/governance](https://github.com/opendckit/governance), with the roster
in [TSC.md](https://github.com/opendckit/governance/blob/main/TSC.md).

Changes here go through a pull request and need an approving review from someone other than
the author.
